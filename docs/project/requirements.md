## US-01.

Как сотрудник ПАО «Татнефть», ответственный за контроль ношения специальной рабочей формы, я хочу, чтобы сервис автоматически выявлял людей без такой формы в видеопотоке, чтобы своевременно обнаруживать нарушения.

Критерии приёмки:

- Сервис обнаруживает людей в кадрах входного видеопотока.
- Для каждого обнаруженного человека сервис определяет наличие специальной рабочей формы.
- Если в кадре обнаружен человек без специальной рабочей формы, сервис регистрирует событие нарушения.

## US-02.

Как сотрудник ПАО «Татнефть», ответственный за контроль ношения специальной рабочей формы, я хочу получать уведомления при обнаружении человека без формы, чтобы оперативно реагировать на нарушение без постоянного просмотра видеопотока.

Критерии приёмки:

- При регистрации события нарушения сервис отправляет уведомление ответственному сотруднику.
- Уведомление содержит время обнаружения и идентификатор источника видеопотока, чтобы сотрудник мог определить, когда и где обнаружено нарушение.
- Если в кадре нет людей или все обнаруженные люди одеты в специальную рабочую форму, уведомление о нарушении не отправляется.

## US-03.

Как представитель заказчика — ПАО «Татнефть», я хочу просматривать сводку выявленных нарушений за выбранный период по источникам видеопотока, чтобы определять участки, требующие дополнительного контроля соблюдения требований к специальной рабочей форме.

Критерии приёмки:

- Заказчик может выбрать период, за который формируется сводка.
- Сводка содержит общее количество зарегистрированных нарушений за выбранный период и их количество по каждому источнику видеопотока.
- Если за выбранный период нарушения не зарегистрированы, сводка показывает нулевое количество нарушений.

### UC-01.

**Актор:** диспетчер

**Цель:** определять и записывать нарушения на устьях

**Предусловие:** Рабочему на устье стало жарко и он снял форму со светоотражающими нашивками.

**Основной сценарий:**

1. В течении трёх секунд сервис определяет отсутствие спецформы
2. Сервис записывает событие в БД
3. Сервис отправляет уведомление диспетчеру
4. Диспетчер подтверждает факт нарушения
5. Работнику выписывается штраф

**Альтернативный сценарий:**

Модель не может определить отсутствие спец. формы. 

**Результат:** нарушение остаётся незамеченным.
