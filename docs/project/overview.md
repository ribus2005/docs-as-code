# Детектор спец. формы

Сервис работает с видеопотоком и автоматически определяет наличие человека без специальной рабочей формы в кадре. 

Заказчик и пользователь: ПАО Татнефть

Основные функции:

Детекция людей;

Классификация одежды;

Отправка уведомлений, если человек не в форме;
