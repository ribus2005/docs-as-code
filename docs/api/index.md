# API

API предоставляет доступ к функциям ИИ-сервиса.

## Основные операции

- `POST /classifications` — выполнить классификацию;
- `GET /alarm_score/{id}` — получить статистику отрицательных результатов;
- `GET /health` — проверить состояние сервиса.

## Спецификация

Полное описание API находится в файле [openapi.yaml](openapi.yaml).
