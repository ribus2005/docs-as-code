# Model Card

## Общая информация

**Название модели:**  
EfficientNet - B0

**Источник:**  
https://huggingface.co/google/efficientnet-b0

**Автор / организация:**  
google

**Задача модели:**  
Классификация изображений

## Использование в проекте

Оценка вероятности ношения формы человеком в кадре.
Оценки вероятности ношения формы складываются в статистику,
если для одного человека было достаточное количество отрицательных
классификаций, отправляется предупреждение.
Так как проект уже реализован, у модели нет api, но если бы он был, 
сервис детекции нарушений формы отправлял бы запросы POST /classification
и регулярно выполнял GET для проверки необходимости отправить предупреждение.

## Входные данные

Изображение человека 224x224 пикселя в RGB.

## Выходные данные

Одно число от 0 до 1 - вероятность ношения формы.

## Метрики качества

В Model Card указано, что модель обучена на ImageNet-1K с входным разрешением 
224 × 224 пикселя. Карточку модели подготовила команда Hugging Face; авторы EfficientNet отдельную карточку для этой модели не предоставили.

Датасет ImageNet-1K:
Top-1 Accuracy: 76.3%
Top-5 Accuracy: 93.2%

Кол-во параметров: 5.3 млн
Кол-во вычислений за один прогон: 0.39 GFLOPS

## Ограничения

Потеря мелких деталей из-за низкого входного разрешения. 
Точность ограничена малым размером модели.

## Не рекомендуется использовать

Не подходит для моей задачи без дообучения на моих данных.
Пришлось изменить архитектуру выходного слоя для работы с одним классом.
Для поиска людей в кадре пришлось использовать YOLO, так как эта модель
справляется с этой задачей крайне плохо.
