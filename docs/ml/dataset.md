# Data Sheet

## Общая информация

**Название датасета:**  
ImageNet-1K

**Источник:**  
[ImageNet Large Scale Visual Recognition Challenge 2012](https://www.image-net.org/challenges/LSVRC/2012/2012-downloads.php).

**Назначение:**  
Обучение и оценка моделей классификации изображений по 1000 категориям объектов.

## Состав данных

**Объём:**  
1 281 167 обучающих, 50 000 проверочных и 100 000 тестовых изображений.

**Тип данных:**  
Цифровые изображения объектов разных категорий.

**Основные поля / признаки:**  
Изображение и метка одной из 1000 категорий, организованных по иерархии WordNet.

## Получение данных

Изображения собраны из интернета и размечены по категориям.

## Предобработка

Для модели проекта указано входное изображение человека размером 224 × 224 пикселя в RGB. Другие действия предобработки в проекте не указаны.

## Ограничения

ImageNet-1K предназначен для общей классификации объектов, а не для определения наличия специальной рабочей формы. Изображения могут отличаться от кадров камер на производстве. Возможны неоднозначные или ошибочные метки.

## Использование в проекте

С ImageNet-1K модель научилась качественно выделять признаки с
изображения. Эти веса являются хорошей базой для дообучения.
